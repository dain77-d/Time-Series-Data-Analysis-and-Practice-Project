# A–D 통합 계획

작성 2026-11-08. 실행 순서는 **C → B → A → D**입니다(C 담당 우선, B가 본론). 모든 모델은 다음을 공유합니다.

- **데이터:** `Dataset_11_07_regions_v5.zip`
- **평가 행:** `Dataset/Evaluation_Contract_20261107/evaluation_grid.parquet`
- **채점기:** `Model/Common/score.py`
- **입력 조건:** 팀 26개(`Model/Common/Regional_Experiments_20261107`) + 대조 3개(CTRL_CN_EAST / CTRL_JP_EAST / CTRL_JP_WEST25)

## 1. 공통 질문과 가설 지도

| 질문 | 가설 (팀 규약 번호) | 주로 답하는 모델 | 교차 확인 |
|---|---|---|---|
| RQ1 어디의 정보가 몇 시간 뒤 예측에 도움이 되나 | H1a 전국 국내(DN) > 국내 67(D67) | B | A, C |
| | H1b 국내 기준선 위 국외 권역의 추가 가치 (ADD_r vs DN, F vs DROP_r) | B | A(그랜저), C(가리기) |
| | H1c 경로(궤적) 정보의 추가 가치 | B(M3T류) | – |
| | 대조: 궤적이 거의 오지 않는 지역은 가치 없음 | B, C | A |
| RQ2 언제 유용하고 어떻게 써야 하나 | H2a 중국 가치는 서쪽 접근·겨울에 큼 | B(조건별 SHAP), C(조건별 가리기) | A(조건별 계수) |
| | H2b 조건별 결합 > Full 단독·고정 결합, 궤적 고도 바람 > 지상 바람 | B Adaptive | C 조건별 의존도 |
| | H2c 그래프의 방향성 효과 | D(방향 vs 대칭화) | C(거리 vs 무작위) |
| 구조 | H4a 그래프가 도움이 되나 | C | D |

판정 규칙은 모두 같습니다. bootstrap 구간 상한 < 0 **그리고** Holm p < 0.05일 때 개선으로 봅니다. 2023으로 설정을 고르고, 2024는 마지막에 한 번만 채점합니다.

**"어디가 중요한가"는 세 가지 다른 측정으로 답하고, 같은 권역을 가리키는지 비교합니다.**
- **정보 가치(재학습):** ADD/DROP — B, C
- **모델 의존도(학습 후):** 가리기·순열 — C·D 가리기, B 그룹 순열
- **예측값 분해:** B TreeSHAP, A 계수·그랜저 검정

## 2. 모델 A — SARIMA / SARIMAX + 그랜저 인과

| 단계 | 내용 |
|---|---|
| 기준 | Persistence, Seasonal naive(채점기가 생성), SARIMA(p,1,q) + 하루·연간 Fourier. 차수는 2021–22 AIC로 고름 |
| 권역별 SARIMAX | 외생변수를 **권역 하나씩** 넣어 봅니다. 국내 7권역 + 국외 8권역 + 대조 3권역의 권역 평균 log1p를 쓰고, 시차 L ∈ {h, h+3, h+6, h+12}는 2023으로 고릅니다 |
| 전체 SARIMAX | 국내 요약 + 중국 권역들을 함께 넣어 계수와 95% 구간을 봅니다 |
| 그랜저 인과 | 2021–22 시간 자료로 권역 평균 → 서울 중구(VAR, 시차 1–24시간, AIC 선택)를 검정합니다. 권역 × 계절(겨울/여름) × 경로(서쪽/그 외)로 나누고 Holm 보정을 합니다 |
| 결과물 | 권역 × 지평 RMSE 개선률, 시차 선택표, 계수표, 그랜저 p값 표 |
| 해석 | 선형 모델 기준 "몇 시간 앞서 움직이는 권역"을 숫자로 보여 주는 기준점입니다 |
| 계산 | CPU만 사용. 적합 1회 약 5분 × 약 70회 → 코어 16개 병렬로 약 1시간 |

## 3. 모델 B — LightGBM 26개 조건 + Adaptive + TreeSHAP (본론)

| 단계 | 내용 |
|---|---|
| 입력 | 팀 `RegionalDataLoader.load_xy(condition, horizon, split)`. D67 1,142열 ~ F 9,670열. 대조 3개는 같은 방식으로 sidecar(`Regions_1107_Station_History`)를 붙입니다 |
| 학습 | 지평별 별도 모델, log1p 목표. 설정 격자는 잎 수 {15, 31} × 특징 샘플링 비율 {0.3, 0.5}(학습률 0.03, 최소 표본 50)이고, 2023 조기 종료로 고른 뒤 시드 3개로 다시 학습합니다 |
| RQ1 | D67 vs DN, ADD_r vs DN(8개), F vs DROP_r(15개), CTRL vs DN(3개)을 채점기의 쌍 비교로 봅니다 |
| H1c | 같은 범위에 경로 특징(KR/CN 전용 allowlist)을 더한 조건과 비교합니다 |
| **TreeSHAP** | F 모델(지평 4개 × 시드 3개)에 `shap.TreeExplainer`(또는 LightGBM `pred_contrib=True`, 정확한 TreeSHAP)를 적용해 2023·2024 모든 예측 시점의 기여를 계산합니다 |
| SHAP 집계 | ① **권역 × 시차**: 열 이름의 측정소와 통계(now/lag01h…lag24h/mean6h…)로 묶어 \|SHAP\| 평균을 냅니다 → "가까운 중국은 6–12시간 전 값이 중요" ② **권역 × 조건**: 계절·경로·지상 풍향·궤적 고도 풍향별 평균 → H2a 그림 ③ **지평별 변화** ④ **고농도 사례**: 상위 10개 사건의 권역별 기여를 역궤적 지도와 겹침 |
| 주의 | 비슷한 측정소끼리는 기여가 서로 나뉘므로 권역 단위로만 보고합니다. SHAP은 예측값 기여이지 정확도 기여가 아니므로 ADD/DROP과 함께 읽습니다 |
| Adaptive (H2b) | ŷ = (1−w)·ŷ_DN + w·ŷ_F. 칸은 ① 경로 방향 ② 지상 풍향 ③ 궤적 고도 풍향, 각각 × 계절입니다. 비교 대상은 Full 단독, **고정 가중 결합**(칸 하나), 단순 규칙 전환입니다. 2023 점수는 가중치를 맞춘 자료라 표본 내 점수이므로 비교는 2024에서 합니다 |
| 결과물 | 권역 가치 히트맵(ADD/DROP), SHAP 권역 × 시차·조건 히트맵, Adaptive 가중치표 |
| 계산 | CPU. 적합 1회 수십 초 × 약 1,300회(조건 29 × 지평 4 × 설정 4 + 시드) → 코어 16개 이상이면 약 2–4시간. SHAP은 모델당 수 분 |

## 4. 모델 C — GRU / GCN-GRU (상세: `docs/C_PLAN.md`)

| 단계 | 내용 |
|---|---|
| 실험 | E1 핵심(GRU vs GCN × D67·DN·F), E2 무작위 그래프 대조, E4 저통과 대조 3개, E3 ADD 8·DROP 15. 시드 3개, 총 177회 |
| 지역 기여 | `occlude.py` + `region_contribution.py`가 권역마다 세 값을 지평별로 냅니다. ① **의존도** = 가렸을 때 RMSE 증가 ② **고유 정보** = DROP 재학습 RMSE − F RMSE ③ **추가 정보** = DN − ADD. 의존도는 계절·경로·지상 풍향·궤적 고도 풍향별로도 냅니다. 유의성은 `score_all.py`의 occlusion 묶음(DM, 블록 구간, Holm)으로 봅니다 |
| 결과물 | 권역 × 지평 히트맵(의존도·고유 정보), 조건별 의존도 표, GCN vs GRU·무작위 그래프 검정표 |

## 5. 모델 D — DCRNN (팀 구현 유지)

| 단계 | 내용 |
|---|---|
| 원칙 | 팀 규약 6절: 48시간 인코더, 24단계 자가회귀 디코더, hidden 32, 확산 2단계를 유지합니다. 노트북은 `Model/DCRNN/V3_Data_20261107` |
| H2c | 같은 노드(national_v3 601개)에서 그래프 3종을 비교합니다: 거리 / 2021–22 궤적 방향 / **그 방향 그래프의 대칭화**. 방향성 효과는 "방향 vs 대칭화"로만 말합니다 |
| C와 연결 | 거리 그래프 D vs C_GCNGRU(F)는 구조 차이로 해석합니다(그래프 효과로 말하지 않음) |
| 지역 기여 | C와 같은 권역 가리기를 해 D의 의존도 히트맵을 만듭니다. 몽골 노드는 그래프상 서울에 도달하지 못하므로 "정보 없음"으로 해석하지 않습니다 |
| 확장(선택) | 학습형 인접행렬(Graph WaveNet식)로 모델이 찾은 연결과 궤적 그래프의 겹침을 봅니다 |
| 계산 | GPU. 실행 1회가 C보다 무겁습니다(디코더 24단계). 그래프 3 × 시드 3 = 9회를 L4 4장에서 돌리면 약 3–6시간 |

## 6. 종합 (발표용)

1. **지평별 개선률 그림:** x축 3/6/12/24h, y축 persistence 대비 RMSE 개선률, 선은 A·B·C·D의 F 조건, 오차막대는 블록 bootstrap 구간
2. **"어디" 일치표:** 행은 권역, 열은 A 그랜저·계수 / B ADD·DROP / B SHAP / C 가리기·DROP / D 가리기, 색은 순위. 같은 권역이 위에 오면 결론을 신뢰할 수 있습니다
3. **"언제" 그림:** 권역 × 조건(경로·궤적 고도 풍향·계절) 히트맵(B SHAP vs C 의존도), Adaptive 가중치
4. **대조:** 저통과 지역(중국 동부, 일본 동해 쪽)의 가치가 0 근처인지. 0이 아니면 그 크기를 공통 기상 변동의 기준선으로 보고합니다
5. **한계:** 예측 정보이지 배출 기여·인과가 아닙니다. 2023 겨울 44일 결측, 몽골 2023 결측, 2024는 재평가 구간입니다

## 7. 서버 계획 (gp4l16-g3: L4 24GB × 4)

| 작업 | 자원 | 예상 시간 |
|---|---|---|
| C 177회 + 가리기 | GPU 4장, `--gpus 4 --per-gpu 2` | **약 4–7시간** |
| B 약 1,300회 + SHAP | CPU 코어 전부 | 약 2–4시간 (C와 동시에 가능) |
| A 약 70회 + 그랜저 | CPU | 약 1시간 |
| D 9회(+확장) | GPU 4장 | 약 3–6시간 |

C와 B·A를 동시에 돌리면 전체 약 **10–14시간**입니다. 시간 추정은 C의 CPU 측정과 연산량에서 계산한 것입니다. 첫 GCN 로그의 epoch당 초로 다시 확인합니다.
