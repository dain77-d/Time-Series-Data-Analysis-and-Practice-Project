# EDA (탐색적 자료 분석)

서울 중구 PM2.5 예측에 쓰는 팀 데이터셋(`data_v5`)을 여덟 가지 유형으로 나눠 탐색했습니다. 그림 56장, 표 59개입니다.

- **기간:** 학습 구간 2021–22만 씁니다. 모델 오차 분석(e9)만 2023 검증 예측을 쓰고, 2024는 쓰지 않습니다.
- **계획:** 처음 세운 항목 목록은 [PLAN.md](PLAN.md)에 있습니다.

## 핵심 발견

1. **자료:**
   - 입력 측정소 650곳의 가용률은 대부분 92–99%입니다.
   - 다만 중국 오류값(9985), PM2.5 > PM10 1만 7천 시간, ASOS 강수 공란 88–89% 같은 문제가 있습니다. → 1
2. **서울 PM2.5:**
   - 겨울·봄에 높고 여름에 낮습니다.
   - 주기로 설명되지 않는 변동이 51%입니다.
   - 24시간 뒤 값과 현재 값의 상관은 0.45뿐입니다. → 2
3. **기상:**
   - 약한 바람, 겨울의 따뜻하고 습한 정체 날에 높습니다.
   - **백령도에 서풍이 불면 12시간 뒤 서울이 평균 +8.8 µg/m³ 오릅니다.** → 3
4. **공간:**
   - 같은 시각에는 중국과 서울의 상관이 약합니다(0.10).
   - **시차를 맞추면 중국 권역이 서울보다 12–24시간 앞서고**, 환산 속도는 시속 35–46 km로 일정합니다.
   - 일본은 반대로 서울보다 늦습니다. → 4
5. **이동경로:**
   - 서해를 건너오는 경로는 평균 27, 동쪽 경로는 10 µg/m³입니다.
   - 2022년 설날에는 중국 불꽃놀이 급등이 백령도(+8시간) → 서울(+21시간)로 퍼지는 모습이 보입니다.
   - 고농도 상위 20개 중 12개는 백령도가 먼저 오른 수송형입니다. → 5
6. **성분:**
   - 백령도와 서울의 PM2.5는 비슷하지만, PM2.5당 NO₂는 서울이 5배 많습니다.
   - 서쪽 경로는 모든 오염물질이 높습니다. → 6
7. **예측:**
   - 상류와 서울의 농도 차이가 앞으로의 변화를 가장 잘 알려 줍니다(24시간 스피어만 +0.57).
   - C_GRU에서 해외 정보는 평균으로는 효과가 없습니다. 하지만 **정체·서쪽 경로의 24시간 예측에서 RMSE를 0.75–1.51 줄입니다.** → 7

8. **다지점 네트워크:**
   - 측정소 650곳 모두에서 **서쪽일수록 먼저, 동쪽일수록 늦게** 움직입니다. 중국 북부는 서울보다 12–20시간, 서해 섬·해안은 2–3시간 앞서고, 일본은 12–21시간 늦습니다.
   - 큰 사례 4개 모두에서 중국 북부 → 한국 → 일본 순으로 정점이 이동합니다.
   - 서쪽 경로일 때는 중국과 한국이 함께 높아서, 수송과 광역 정체가 겹칩니다.
   - 국가배경 섬 측정소는 NO₂가 적은데도 PM2.5가 도시와 비슷합니다. → 8

**종합:** 국외 정보는 "항상"이 아니라 **특정 경로와 시차에서** 가치가 있습니다. 경로와 시차를 고려해 정보를 쓰는 방식이 다음 실험 방향입니다.

## 실행

```bash
python EDA/01_data_inventory_and_quality/eda_e0_overview.py
python EDA/05_transport_pathways_and_events/eda_e5_trajectories.py
```

- 저장소 옆에 `data_v5`를 두거나 `TSA_DATA`로 위치를 지정합니다.
- 측정소 PM2.5는 `C_graph/cdata.py`가 만드는 캐시(`work/c_universe.npz`)를 씁니다. 캐시가 없으면 처음 실행할 때 만듭니다.
- **실행 순서:** `05/eda_e5_trajectories.py`를 먼저 실행해야 합니다. 경로 군집 표를 5·6·7번 분석에서 씁니다. 나머지는 순서가 상관없습니다.
- 공통 함수는 `common.py`에 있습니다. 각 스크립트는 자기 폴더의 `figures/`, `tables/`에 결과를 저장합니다.
